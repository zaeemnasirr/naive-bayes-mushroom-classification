README.txt — Naive Bayes  

Files you should have:
1) main.ipynb (or main.py) — your Colab notebook/script with:
   - data loading
   - 80/20 train–test split (fixed random_state=35, stratify=y)
   - Naive Bayes from scratch (Laplace smoothing + log-probabilities)
   - Part 2 evaluation metrics
   - Bonus accuracy vs training size plot
2) mushroom_input.csv — provided sample input file 
3) output_mushroom_input.csv — predictions produced by the code 



How to run (Google Colab):
1) Upload these files to Colab:
   - Mushroom.csv
2) Run all cells from top to bottom.
3) The notebook prints metrics for Part 2A/2B and the explanation for Part 2C comparison.
4) The notebook writes predictions for mushroom.csv to output_mushroom.csv.
